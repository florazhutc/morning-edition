The course has 13 modules, with the first 6 foundation modules free, module 7-13 with free readings but guide labs for a one-time price of $49.

Actionable Insight

This beginner Python course simplifies the learning process by running entirely in the browser and visualizing code output as drawings, bypassing traditional setup complexities.
