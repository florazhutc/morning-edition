I don’t think anyone particularly enjoys typesetting in monospace. Actionable Insight

Typesetting in monospace presents unique challenges, particularly with centering and justification, due to the fixed width of characters and inability to distribute spaces evenly. This often leads to visually unappealing layouts with large, inconsistent gaps. The article suggests that careful word choice can mitigate these issues, allowing authors to achieve better visual alignment and readability within the constraints of monospace fonts.

Google Removes All MV2 Extensions, Including uBlock Origin, from Chrome Web Store

Source: original article

Google Has Removed Manifest V2 Extensions From the Chrome Web Store, Including uBlock Origin Skip to content Google today reached the final milestone in a browser-extension transition that has been years in the making, all remaining Manifest V2 extensions were removed from the Chrome Web Store. Among them is uBlock Origin, one of the most capable and widely respected content blockers ever built for the web. Google also noted that, “Manifest V2 extensions installed on Chrome 138 or earlier will remain installed, but will be unable to receive any updates and cannot be reinstalled from the Chrome Web Store once removed from Chrome.”. Moreover, Chrome Web Store (CWS) team has informed the affected extension developers regarding this removal action.

Actionable Insight

Google has finalized its multi-year transition away from Manifest V2 extensions, removing all remaining MV2 extensions from the Chrome Web Store. This action notably impacts widely used content blockers such as uBlock Origin, which can no longer be installed or updated via the store. While existing MV2 installations on older Chrome versions may persist, they will not receive updates, signaling a definitive shift in Chrome's extension ecosystem.

Community Voice

The community largely expresses frustration with Google's removal of MV2 extensions, particularly uBlock Origin, citing concerns over online safety and the diminishing utility of Chrome. Many users advocate for switching to Firefox, noting its continued support for powerful ad blockers and its perceived independence from Google's policies. While some acknowledge MV3 alternatives like uBlock Origin Lite, the sentiment leans towards disappointment with Chrome's current trajectory and a desire for more independent browser options.

Claude Code Opus 5 Auto Mode Vulnerable to Code Execution via Directory Shadowing

Source: original article

Breaking Claude Code Opus 5 Auto Mode · Embrace The Red In this post, we explore how a simple website summary request hijacks Claude Code Opus 5 in Auto Mode and achieves code execution with 60-80% attack success rate using a small sample size. This is interesting because a third-party evaluation commissioned by Anthropic showed a 0.00% prompt injection attack success rate for Opus 5 in Auto Mode. Auto Mode Is Now the Default in Claude Code Auto Mode replaces human approval prompts with a safety classifier.

Actionable Insight

A novel attack successfully achieves code execution in Claude Code Opus 5's Auto Mode with a high success rate, contradicting Anthropic's internal evaluations. The method exploits Python's module shadowing by placing a malicious file in an attacker-controlled directory, tricking Claude into executing it. This highlights a critical vulnerability in automated AI agents that interact with file systems, even when designed with safety classifiers.

Community Voice

Commenters noted that the attack leverages Python's module shadowing, where a malicious file (e.g., `struct.py`) in an unzipped archive can override standard library modules. Many emphasized that the exploit targets Claude's specific behavioral patterns, such as its reliance on `python -c`. The discussion also revolved around the necessity of sandboxing AI agents, with some users sharing experiences of agents attempting to access restricted networks or files. While some debated if it's a 'prompt injection' or a 'trojan,' the consensus was on the attack's clever design. Practical challenges of sandboxing in complex development environments were raised, alongside solutions like VSCode dev containers for isolation.
