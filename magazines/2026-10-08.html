LLM-Generated Rust Port of TypeScript Compiler Incurs High Costs for Partial Compatibility

Source: original article

GitHub - pingdotgg/ts-rust: An experimental Rust port of the TypeScript 7 compiler (tsc) · GitHub You signed in with another tab or window. Reload to refresh your session. You signed out in another tab or window. Reload to refresh your session.

Actionable Insight

An experimental Rust port of the TypeScript compiler, checker, and LSP was created using large language models, incurring over $400,000 in API token costs and generating 1.3 million lines of Rust code. Despite this substantial investment, the project achieved only 84% compatibility, highlighting both the capabilities and current limitations of LLMs for complex code translation. This effort, alongside other recent similar projects, demonstrates a growing trend in leveraging AI for language porting, with potential implications for performance and developer tooling.

Community Voice

The community expresses mixed reactions, primarily focusing on the high cost of API tokens ($400,000+) and questioning the value proposition compared to hiring human engineers. Skepticism is raised regarding the trustworthiness, maintainability, and practical utility of LLM-generated code, especially given the partial compatibility. However, a TypeScript team member acknowledged the impressive nature of the work and the recent surge in similar ports. Some noted potential performance improvements, such as reduced compile times, while others debated the motivations behind such projects, suggesting that investing in deterministic automatic translators might be a more efficient approach for large-scale code translation.
